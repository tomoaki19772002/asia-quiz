# アジアクイズ 2分チャレンジ

スマホ向けのアジア地理クイズ。`index.html` を開くだけで遊べます(ローカルサーバー経由推奨)。

対象は東アジア・東南アジア・南アジア・中東・中央アジアの47か国。

1. 地図上で光った国の名前を4択で当てる
2. つづけて、その国の国旗を4択で当てる
3. さらに、その国の首都を4択で当てる

- 正解 +1 / まちがい −1(まちがえると正解を表示)、制限時間 2分
- 残り時間・ポイントをリアルタイム表示、BGM・正解音・不正解音あり(Web Audioで合成)
- 選択肢は地図上で近い国から選ぶので、まぎらわしい問題になります

## データ

- 地図: [Natural Earth](https://www.naturalearthdata.com/) 1:50m(パブリックドメイン)を簡略化して `map-data.js` にしています。モルディブは簡略表示です。
- 国旗: [flag-icons](https://github.com/lipis/flag-icons)(MIT)の SVG を `flags/` に収録しています。
